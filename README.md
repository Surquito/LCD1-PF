# Asistente Inteligente de Finanzas Personales y Clasificación de Gastos

Tratará de un asistente financiero automatizado que opera a través de la consola de comandos, diseñado para ayudar a los usuarios a registrar, categorizar y analizar sus movimientos económicos diarios de manera inteligente.
